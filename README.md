# QuickShell

一个轻量的 Windows 命令快捷运行面板。

全局快捷键（默认 `Ctrl + Space`）随时唤起一个命令面板：**输入框既是命令搜索框，也是临时命令行**。应用启动后驻留托盘，面板失焦自动隐藏。

## 开发

```powershell
npm install
npm run tauri dev
```

## 构建

```powershell
npm run build
npm run tauri build
```

## 快捷输入方式

命令面板只有一个输入框，同时承担两种输入方式：

- **搜索已保存命令**：按名称或命令内容模糊匹配，`↑ ↓` 选择、`Enter` 运行，固定的命令始终排在最前。
- **直接输入命令**：输入没有匹配到任何已保存命令时，面板会把输入当作一条临时命令，提供「直接运行」与「保存为命令」两个动作，回车即可执行或沉淀为常用命令。

命令会启动独立的系统控制台（CMD / PowerShell / PowerShell 7 / Git Bash），QuickShell 不参与控制台输入输出，用户可以直接在其中交互。

## 动态参数

命令内容支持 `{{参数名}}` 占位符，例如：

```text
python deploy.py --build-no {{buildNo}}
```

运行时面板会就地提示填写参数（自动带入上次的取值），并按目标 Shell 的规则转义后启动；重新运行无需重复配置任何参数项。

### 扩展参数

在管理模式中可以为命令配置一个扩展参数，占位符固定为 `{{ext}}`（可一键插入到命令），两种模式二选一：

- **自动递增**：可设置起始值与步长。首次运行使用起始值，之后每次成功运行自动加步长，全程无需手动输入，适合版本号、序号类场景；
- **每次输入**：每次运行时弹框输入数字或字母，自动带入上次的取值。

计数与上次取值保存在本机 `command-runtime-values.json`，删除命令不影响其他命令的计数。

## 命令管理

在面板内按 `Ctrl + E`（或点击右上角「管理」）进入管理模式：新建、编辑（名称 / Shell / 命令 / 初始目录 / 固定到顶部）与删除都在同一个窗口完成，带未保存修改提示与删除确认，不会误丢改动。命令配置保存在本机 `commands.json`。
